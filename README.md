## Hey, I’m Kushan 🙋🏻‍♂️

Senior Software Engineer at HSBC with a backend + platform focus. I ship governed data access experiences, Kubernetes-first delivery, and contract-first APIs. Always tuning the SDLC so teams ship fast without trading away security.

**Currently** — platform automation and governed data access for teams on Hadoop/Doris/Kafka/Redis.

**Key skills**

- **APIs** — contract-first OpenAPI, versioned/compatible services, resilient error models; Java/Spring Boot backends, React/Next.js + Tailwind frontends
- **Languages** — Java, TypeScript/JavaScript, Python, Scala, C++
- **Data & streaming** — governed access + audited writebacks across Hadoop, Spark/PySpark, Impala, Doris, Hive, Kafka, Redis; PostgreSQL, MySQL, MongoDB, Elasticsearch
- **Kubernetes & DevOps** — Docker, Kubernetes/Helm, GitHub Actions, Jenkins, Ansible, Git; multi-env promotion, rollbacks, config separation, resource tuning
- **Observability & orchestration** — Splunk, Airflow, Control-M, Yarn; quality/security gates (Sonar, Nexus IQ)
- **Security & reliability** — zero-vuln gating, hardened base images, secrets hygiene, sound authz; schema evolution, freshness-vs-latency tradeoffs
